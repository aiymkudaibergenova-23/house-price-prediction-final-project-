# House Price Prediction 🏠

This is my final project for the Deep Learning course at Narxoz University (Spring 2026).

## What is this project about?
The goal is to predict the sale price of houses based on their features like size, location, year built, and many others. I am using the Kaggle House Prices dataset which has 79 features and 1460 houses.

## Why this problem?
House prices are hard to estimate manually. A model that can predict prices based on real data could help buyers and sellers make better decisions.

## Dataset
- Name: House Prices - Advanced Regression Techniques
- Source: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques
- Size: 1460 training samples, 79 features
- Target: SalePrice (in USD)

## My Plan
1. Explore and clean the dataset (Week 1)
2. Build a baseline MLP model (Week 2)
3. Improve the model with regularization and feature engineering (Week 3)
4. Final evaluation and report (Week 4)
