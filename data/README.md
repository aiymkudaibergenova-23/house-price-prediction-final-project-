# Data

## Dataset: House Prices - Advanced Regression Techniques

Source: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data

## How to Download

1. Go to the Kaggle link above
2. Sign in to your Kaggle account
3. Click "Download All"
4. Extract the zip file
5. Place train.csv and test.csv into this data/ folder

## Files
- train.csv — 1460 rows, 79 features + SalePrice target
- test.csv — 1459 rows, 79 features (no target)
- data_description.txt — description of all features

## Note
Raw data files are not committed to this repository.
Download them manually from Kaggle using the link above.
